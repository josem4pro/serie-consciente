# Estudio de Movimiento — venta de la Kinesis

Página de venta de la Technogym Kinesis Personal Heritage de Milagro Ortiz, publicada con
GitHub Pages en estudiodemovimiento.es. No indexar.

**La página está cifrada.** `index.html` es solo la pantalla de contraseña; el contenido real
(página, fotos y vídeo) va en `contenido.bin`, cifrado con AES-256-GCM (clave PBKDF2-SHA256,
600.000 iteraciones) y se descifra en el navegador. El repo es público: nada legible de la
página nueva vive acá. La contraseña no está en el repo.

Fuente y script de cifrado: `../venta-v2/` (`publicar/`). Hasta el 23-sep-2026 esta portada era
la «Serie Consciente» (commit 194aed2).
